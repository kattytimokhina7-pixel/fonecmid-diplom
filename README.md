# Инструкция по начальной настройке конфигурации «Управление IT-фирмой»

Эта инструкция предназначена для администратора и специалистов заказчика. Она описывает, что нужно сделать в уже работающей базе, чтобы начать использовать новые подсистемы: «Обслуживание клиентов (ВКМ)» и «Расчет зарплаты (ВКМ)». 

Внимание! Перед началом сделайте резервную копию базы. Все действия выполняются в режиме «1С:Предприятие» пользователем с правами администратора.

*Все ниже перечисленные справочники, регистры и документы добавлены в новую служебную подсистему «Добавленные объекты (ВКМ)». 

## Пользователи и права доступа

Для обеспечения информационной безопасности и разделения полномочий назначьте сотрудникам новые профили групп доступа. Чтобы овые профили групп доступа отобразились в списке, базу нужно один раз запустить в режиме предприятия с дополнительным параметром /C ЗапуститьОбновлениеИнформационнойБазы. 

*Без этого шага назначить новые профили не получится. 

### Запуск обновления информационной базы

1. Закройте 1С:Предприятие, если оно открыто.
2. Откройте окно запуска 1С:Предприятие (ярлык на рабочем столе или через меню «Пуск»).
3. Выделите нужную информационную базу и нажмите Изменить.
4. В открывшемся окне нажмите команду «Далее» и найдите поле «Дополнительные параметры запуска».
5. Введите в него строку: /C ЗапуститьОбновлениеИнформационнойБазы.
6. Нажмите Готово, затем запустите базу в режиме запуска — «1С:Предприятие».
7. При запуске система выполнит обновление информационной базы. Дождитесь его завершения и очистите параметр запуска.

После обновления в списке профилей групп доступа появятся новые профили. 

### Назначение профилей групп доступа

Перейдите в «Администрирование» → «Настройка пользователей и прав» → (раздел «Группы доступа») «Профили групп доступа».

Специалист по обслуживанию клиентов — назначается специалистам, которые выполняют обслуживание клиентов. Они создают документы «Обслуживание клиента». Документы обслуживания вводят специалисты и менеджеры. Специалистам также доступен отчёт по выработке специалистов.

Менеджер по обслуживанию клиентов — назначается сотрудникам отдела по работе с клиентами. Они создают и редактируют документы «Обслуживание клиента». Документы обслуживания вводят специалисты и менеджеры.

Бухгалтер ИТ-фирмы с массовым созданием реализаций — назначается сотрудникам бухгалтерии. Они работают с документами покупки-продажи и используют массовое создание документов «Реализация товаров и услуг» по абонентским договорам. Бухгалтерам доступен отчёт по анализу выставленных актов.

Кадровик-расчётчик — назначается кадровику, главному бухгалтеру или сотруднику, который занимается расчётом зарплаты и планированием отпусков. Вводом информации о заработной плате и плановых отпусках занимаются кадровики-расчётчики. Им доступны отчёты по зарплате, отпускам, а также отчёт по выработке специалистов.

## Заполнение констант

Для корректной работы автоматизированных алгоритмов и Telegram-бота заполните следующие константы:

ВКМ_НоменклатураРаботыСпециалиста — услуга для почасовых работ специалиста;
ВКМ_НоменклатураАбонентскаяПлата — услуга для ежемесячной абонентской платы;
ВКМ_ТокенТелеграмБота — токен Telegram-бота;
ВКМ_ИдентификаторГруппыТелеграм — ID группы или чата, куда бот будет присылать уведомления.

Номенклатуру удобнее создать заранее: Справочники → Номенклатура, вид номенклатуры — «Услуга». Например, «Работы специалиста» и «Абонентская плата». Если такие услуги уже есть, просто выберите их.

*Все константы выведены в подсистеме «Обслуживание клиентов (ВКМ)» раздел «Сервис».

------

## Настройка Telegram-оповещений

1. Создайте бота через @BotFather (с подробным описанием можно ознакомиться в [Интеграция с Телеграм](https://github.com/netology-code/fonecmid-diplom/blob/main/tasks/telegram.md)) и получите его API-токен.
2. Добавьте бота в рабочую группу Telegram, выдайте ему права администратора и узнайте ID группы.
3. Впишите токен и ID группы в соответствующие константы.
4. Перейдите в Администрирование → Обслуживание → Регламентные и фоновые задания. Проверьте что включено задание «Отправка уведомлений телеграм (ВКМ)» и задайте расписание, например каждые 5 минут.
5. Запустите задание вручную и проверьте, что сообщение уходит в группу.

*Уведомления будут отправляться при создании документа «Обслуживание клиента», а также при изменении даты или специалиста в уже созданном документе.

## Договоры с клиентами

В справочнике Договоры контрагентов откройте существующий или создайте новый договор с клиентом. В поле «Вид договора» выберите «Абонентское обслуживание» и заполните появившиеся реквизиты: дата начала и дата окончания договора, сумма абонентской платы и стоимость работы специалиста. 

Договор будет активен для документов обслуживания, если текущая дата попадает в указанный период. Договор также станет доступен для докумнета «Реализация товаров и услуг» для возможности автозаполнения такого документа суммой ежемесячной абонентской платы и суммой за выполненные в течения месяца работы по данным документов «Обслуживание клиентов».

## Графики работы

Перейдите в «Расчет зарплаты (ВКМ)» → (раздел «Справочники») Графики работы. Заполните справочник графиков работы, если он ещё пуст.

Перейдите в «Расчет зарплаты (ВКМ)» → (раздел «Регистры») Графики работы. Для расчёта оклада нужен актуальный график работы. Заполните рабочие дни за каждый месяц на текущий год.

*Без заполненного графика оклад сотрудников рассчитываться не будет.

------

## Сотрудники и условия оплаты

Перейдите в «Расчет зарплаты (ВКМ)» → (раздел «Справочники») Сотрудники. Заполните справочник сотрудников, если он ещё пуст, и укажите соответсвующий график для каждого сотрудника.

Перейдите в «Расчет зарплаты (ВКМ)» → (раздел «Регистры») Условия оплаты сотрудников.

Создайте запись для каждого сотрудника указав его оклад и/или процент от выполненных работ. При настройке условий оплаты создайте запись на каждого сотрудника, указав его оклад и, если нужно, процент от выполненных работ. Для административного персонала процент можно оставить нулевым. Для специалиста укажите процент, например 15, если он получает 15% от суммы работ.

*Без этих данных оклад и процент специалиста рассчитываться не будут.

## Начальные данные

Если переход на новую функциональность происходит с начала месяца и необходимо сразу видеть данные для отчётов и расчёта зарплаты:

1. Введите документы «Обслуживание клиента» за прошлые периоды и проведите их;
2. Для фиксации долга перед сотрудником используйте документы «Начисление зарплаты» или «Начисление фиксированной премии» за предыдущий период;
3. Не создавайте на одного сотрудника за один и тот же период две строки по видам «Оклад» и «Отпуск» одновременно»;
4. Выплаты оформляйте документом «Выплата зарплаты»;
5. График отпусков вводите документом «График отпусков».
