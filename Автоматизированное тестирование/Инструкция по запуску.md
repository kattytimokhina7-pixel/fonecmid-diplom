# Инструкция по запуску сценариев автоматизированного теста

Автотесты реализованы с помощью Vanessa Automation и проверяют работу подсистемы «Обслуживание клиентов». Ниже описана подготовка и порядок запуска сценариев.

------

## Подготовка тестовой базы

Автотесты запускаются на отдельной копии базы, чтобы не затрагивать рабочие данные.

Сделайте копию базы, в которой уже выполнена начальная настройка. В копии не должно быть документов «Обслуживание клиента» и «Реализация товаров и услуг». Если они есть, удалите или пометьте их на удаление. Данные по сотрудникам должны быть настроены.

Для удобства можно использовать подготовленную тестовую базу «Автоматизированное тестирование.dt».
В базе заранее заполнены необходимые справочники и регистры, содержащие данные о сотрудниках, клиентах, организациях и других объектах, необходимых для выполнения сценария. Документы «Обслуживание клиента» и «Реализация товаров и услуг», которые являются результатом выполнения автотеста, в подготовленной базе отсутствуют.

------

## Установка Vanessa Automation

1. Скачайте фреймворк Vanessa Automation из официального git-репозитория.
2. Распакуйте архив в отдельную папку на диске C. Путь не должен содержать кириллических символов.
3. В этой же папке создайте подкаталог для хранения сценариев, например project.

------

## Настройка тестовой базы

1. Откройте тестовую базу в режиме Конфигуратор.
2. Перейдите в раздел Администрирование → Пользователи.
3. Для пользователя Администратор снимите флаг «Защита от опасных действий» и закройте конфигуратор.
4. Откройте окно запуска 1С:Предприятие, выделите тестовую базу и нажмите Изменить.
5. В открывшемся окне нажмите команду «Далее» и найдите поле «Дополнительные параметры запуска» 
6. Введите в него строку: /TESTMANAGER
7. Нажмите Готово, затем запустите базу в режиме запуска — «1С:Предприятие».

*Без параметра /TESTMANAGER фреймворк Vanessa Automation не сможет подключиться к базе и управлять сеансами.

------

## Запуск Vanessa Automation

1. В запущенной тестовой базе откройте меню Файл → Открыть (или нажмите Ctrl+O).
2. Выберите файл vanessa-automation.epf из папки, куда вы распаковали фреймворк.
3. Обработка предложит включить использование внешней компоненты VanessaExt — нажмите ОК.
4. На вкладке Сервис проверьте, что язык фича-файлов — Русский.
5. В разделе Системные каталоги укажите путь к созданной папке project.
6. На вкладке Библиотеки проверьте путь к каталогу features\Libraries внутри папки Vanessa Automation.

------

## Добавление клиентов тестирования

Для выполнения сценариев нужны клиенты с разными правами доступа.

1. Перейдите на вкладку Клиенты тестирования.
2. Нажмите Добавить и создайте трёх клиентов:
    Специалист — с дополнительным параметром /N"Специалист" (или имя пользователя с профилем специалиста);
    БухгалтерИТФирмы — с параметром /N"БухгалтерИТФирмы";
    Менеджер — с параметром /N"Менеджер".
3. Для каждого клиента укажите:
    тип клиента — Тонкий;
    путь к инфобазе — путь к тестовой базе;
    имя компьютера — localhost;
    порт запуска — свободный порт или 1.
4. Подключите каждого клиента, нажав кнопку подключения.

*Клиенты должны быть созданы в тестовой базе как пользователи с соответствующими профилями доступа.

------

## Загрузка и запуск сценария

1. Вернитесь на вкладку Запуск сценариев.
2. Нажмите Открыть feature файл или выберите Загрузить один файл.
3. Выберите один из предзагруженных сценариев из папки Features.
4. После загрузки сценария нажмите кнопку Выполнить (зелёный треугольник).
5. Если аккаунт пользователя защищён паролем, введите пароль и нажмите Войти.
6. Дождитесь завершения сценария. Vanessa Automation подаст звуковой сигнал и покажет результат.

------

## Проверка после настройки

- Все автотесты запускаются на приложенной демонстрационной базе. В ней уже заполнены справочники и настроены тестовые данные.
- Перед запуском убедитесь, что в базе нет документов «Обслуживание клиента», «Реализация товаров и услуг» и договоров контрагентов.
- Если сценарий не запускается, проверьте:
    1. Установлен ли параметр /TESTMANAGER;
    2. Снята ли защита от опасных действий у пользователя Администратор;
    3. Подключены ли клиенты тестирования;
    4. Указан ли правильный путь к папке project и библиотекам Vanessa Automation.
